מדריך הסקריפטים (Scripts Directory) ⚙️

תיקיית ה-scripts מכילה אוסף של כלי אוטומציה שמטרתם לחסוך שעות של עבודה ידנית.
להלן פירוט של כל סקריפט ותפקידו במערכת.

📦 בנייה, אריזה והפצה (Build & Package)

build.js Node.js

מנוע הבנייה הראשי. הסקריפט לוקח את כל קבצי המקור (HTML/CSS), מזריק פנימה את העיצובים ב-inline (עבור Moodle), ומייצר את התוצרים הסופיים לתיקיית dist.

npm run build

# או לניסוי ספציפי:
npm run build:exp01
npm run build:exp02
# וכן הלאה...

package_moodle_experiments.py Python

אורז את כל קבצי ה-HTML של הניסויים השונים לקבצי ZIP ייעודיים, המוכנים לייבוא ישיר לתוך תוסף Moodle Book. ניתן לארוז כל ניסוי בנפרד:

npm run package:exp01
npm run package:exp02
npm run package:exp03

package_full_distribution.py Python

מייצר חבילת הפצה מלאה (Distribution) הכוללת את כל חומרי המעבדה בגרסתם הסופית והנקייה.

python scripts/build_and_package/package_full_distribution.py

package_exp04_exp05.py Python

סקריפט אריזה המיועד ספציפית לניסויים מתקדמים (ניסוי 4 ו-5), מכין אותם להעלאה למודל. ניתן לארוז כל ניסוי בנפרד:

npm run package:exp04
npm run package:exp05

rebuild_and_clean_dist.py Python

מוחק את התוצרים הישנים מתיקיית ה-dist, ומריץ בנייה מחדש מלאה ונקייה מאפס.

🔗 ניהול קישורים ותיקוני HTML

update_moodle_links.py Python

מעדכן באופן גורף קישורים פנימיים וחיצוניים בתוך קבצי ה-HTML כדי לוודא שאינם נשברים בתוך סביבת Moodle.

validate_links.py Python

סורק את כל קבצי הפרויקט, מוודא שכל הקישורים (תמונות, דפים) תקינים ומתריע על קישורים שבורים (404).

normalize_moodle_links.py Python

מנרמל קישורים לפורמט הסטנדרטי של Moodle (הפיכת נתיבים יחסיים למוחלטים במידת הצורך).

fix_card_headers.py & upgrade_tables.py Python

סקריפטים עיצוביים שעוברים על קבצי התוכן ומשדרגים אוטומטית טבלאות וכותרות כרטיסיות למראה ה"פרימיום" המעוצב שלנו.

comment_html_files.py Python

מוסיף הערות (Comments) וסימניות בקוד ה-HTML כדי להקל על קריאות ותחזוקה עתידית של הקוד.

🧠 משימות ובחנים אוטומטיים (H5P & MATLAB Grader)

generate_all_grader_tasks.js Node.js

הסקריפט שיצרנו לאחרונה! פורס אוטומטית את כל תבניות ה-MATLAB Grader לניסויים 2 עד 5 (פרקי PreLab ו-InLab) בשפה האנגלית והעברית.

node scripts/matlab_grader/generate_all_grader_tasks.js

scaffold_grader_templates.js Node.js

גרסת בסיס ליצירת תבניות ראשוניות (שלד ריק) עבור MATLAB Grader.

generate_exp0X_prelab_h5p.js Node.js

משפחת סקריפטים (לניסויים 1, 2 ו-3) שמייצרים אוטומטית שאלות אינטראקטיביות ובחנים מסוג H5P ו-Moodle XML עבור פרקי ההכנה.

🛠️ כלי עזר (Utilities)

optimize_images.py Python

רץ על כל התמונות בתיקיית המקור באופן מקבילי (Multi-threaded) וממיר אותן לפורמט WebP העדכני. מכווץ את התמונות מבלי לפגוע באיכות וחוסך עשרות אחוזים במשקל ה-ZIP ומשפר דרמטית את מהירות הטעינה ב-Moodle.

inspect_zips.py Python

פותח וסורק תוכן של קבצי ZIP שנוצרו כדי לוודא שאין בהם קבצי זבל או שגיאות קידוד לפני ההעלאה.

package_mastech_only.py
package_measuring_equipment.py Python

סקריפטים ספציפיים לאריזת מדריכי הציוד (כגון מולטימטר Mastech וציוד מדידה כללי) לפורמט נפרד.
