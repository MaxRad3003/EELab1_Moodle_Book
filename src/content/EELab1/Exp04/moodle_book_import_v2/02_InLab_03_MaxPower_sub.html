חזרו עבור עומס ממשי, עומס עם היגב קבוע ועומס שבו ניתן לשנות היגב. כתבו את התנאי שהתקבל לנקודת המקסימום.

הנחיות לכתיבת כלי עזר חישובי ב-MATLAB

כדי לאמת את התוצאות שלכם ולהבין טוב יותר את משפט העברת ההספק המקסימלי, עקבו אחר ההנחיות ליצירת סקריפט MATLAB קצר שישרטט את הגרף התיאורטי ויציב עליו את הנקודות שמדדתם בפועל.

% 1. הגדרת פרמטרים תיאורטיים (לפי רכיבי המעגל)
Vs = 10; % מתח המקור [V]
Rs = 50; % התנגדות פנימית של המקור [Ohm]
RL_th = linspace(1, 150, 100); % וקטור עומסים תיאורטי מ-1 עד 150 אוהם

% 2. חישוב הספק תיאורטי על העומס
PL_th = (Vs ./ (Rs + RL_th)).^2 .* RL_th;

% 3. שרטוט הגרף התיאורטי
figure;
plot(RL_th, PL_th, 'LineWidth', 2, 'Color', [0 0.4470 0.7410]);
hold on; grid on;
xlabel('R_L [\Omega]'); ylabel('P_L [W]');
title('העברת הספק מקסימלי - תיאוריה מול מדידה');

% 4. הוספת נקודות המדידה שלכם (הזינו את הנתונים שמדדתם!)
RL_measured = [10, 20, 30, 40, 50, 60, 80, 100, 120]; % התנגדות שנמדדה
PL_measured = [...]; % הזינו כאן את וקטור ההספק שחישבתם מהמדידות
