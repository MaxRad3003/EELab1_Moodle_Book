# Uploading H5P Quizzes to Moodle Content Bank

When asked to upload H5P quizzes to Moodle, follow these exact steps that the user has taught:

## Source Directory
All `.h5p` files are located in the working directory under:
`EELab1_Moodle_Book/dist/release/`
Inside this folder, there is a subfolder for each experiment (e.g., `Exp01_Moodle_Distribution`), and inside each there is an `H5P_Quiz` folder containing the `.h5p` files.

## Upload Steps (For each `.h5p` file)
1. Go to the Moodle **Content bank** page.
2. Click on the **Upload** button.
3. In the dialog, click on **Choose a file...**.
4. In the **File picker** window, select **Upload a file** from the side menu, then click on **Choose File**.
5. An OS file selection dialog will open. Navigate to the relevant `H5P_Quiz` folder (e.g., `dist/release/Exp01_Moodle_Distribution/H5P_Quiz/`), select the specific `.h5p` file, and click **Open**.
6. Click the **Upload this file** button at the bottom of the File picker.
7. Verify that the file name now appears in the list/box.
8. Click **Save changes**.
9. Once saved and the H5P preview loads, click **Exit** (or navigate back) to return to the Content bank.

Repeat these steps for **every** `.h5p` file across all experiments.
