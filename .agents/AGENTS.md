# EELab1_Moodle_Book - כללי עבודה ופיתוח (Rules & Guidelines)

קובץ זה מגדיר את הכללים, הארכיטקטורה ושיטות העבודה המומלצות בפרויקט זה. יש לפעול לפי הנחיות אלו בעת ביצוע שינויים, הוספת קוד או כתיבת סקריפטים חדשים.

## 1. מבנה הפרויקט והסקריפטים
תיקיית ה-`scripts` מחולקת לוגית. בעת הוספת סקריפט חדש, יש לשים אותו בתיקייה המתאימה:
- `build_and_package/` - סקריפטים לבניית הפרויקט ואריזת קבצי ה-ZIP.
- `html_and_links/` - סקריפטים לתיקון כותרות, טבלאות ו-HTML ולידציה לקישורים.
- `assessments_and_h5p/` - אוטומציות הקשורות לבחני H5P.
- `matlab_grader/` - מחוללי התבניות עבור MATLAB Grader (ניסויים 2-5).
- `utils/` - כלי עזר שונים (אופטימיזציית תמונות, כלים כלליים).

**חובה לעדכן את מסמך התיעוד** `Scripts_Documentation.html` במקרה של שינוי מהותי בסקריפטים.

## 2. קידוד ותמיכה בעברית
- **סקריפטים ב-Python:** הפרויקט משתמש בנתיבים וטקסטים בעברית. חובה לוודא שכל סקריפט Python תומך בהדפסה למסוף (Terminal) בקידוד `UTF-8`. אם הסקריפט קורס בגלל נתיבים עם עברית (כמו "מעבדה חשמל 1"), יש להזריק קוד לשינוי קידוד המסוף ל-UTF-8.
- יש להשתמש ב- `encoding='utf-8'` בעת קריאה וכתיבה של קבצים בסקריפטים.

## 3. ניהול נתיבים (Path Management)
- **סקריפטים ב-Python:** אין להניח שהסקריפט רץ מתיקיית השורש. יש להשתמש בנתיבים יחסיים ל-`__file__` ולמצוא את נתיב השורש של הפרויקט באופן דינמי (לרוב דרך חיפוש הקובץ `package.json` או תיקיית השורש `EELab1_Moodle_Book`).
- **סקריפטים ב-Node.js:** כנ"ל, יש להשתמש ב-`__dirname` וב-`path.resolve` כדי להבטיח עבודה תקינה מכל מיקום.

## 4. תמונות ואופטימיזציה
- אין להעלות תמונות בפורמט כבד (כמו PNG או JPG גדולים).
- יש להשתמש תמיד בפורמט **WebP** עבור תמונות, על מנת להקטין את משקל קובץ ה-ZIP ולשפר את מהירות הטעינה ב-Moodle.
- במידה ונוספו תמונות חדשות, יש לוודא שהן עוברות דרך סקריפט האופטימיזציה (`optimize_images.py`).

## 5. תהליך הבנייה (Build Process)
- הפרויקט משתמש בפקודות NPM המוגדרות ב-`package.json`.
- כדי לחסוך זמן בנייה, השתמש בפקודות **פרטניות** לניסוי שאתה עובד עליו (למשל `npm run build:exp04` ו- `npm run package:exp04`) במקום לבנות את כל הפרויקט מחדש.
- כאשר מסיימים פיצ'ר או סבב עבודה, יש להריץ `npm run release` או `npm run validate` כדי לוודא שאין שגיאות או קישורים שבורים.

## 6. תבניות MATLAB Grader
- תבניות הקוד, הפתרון ומבחני הבדיקה (Tests) עבור MATLAB נכתבות **באנגלית בלבד** (כדי להתאים למערכת Grader).
- מנגד, ההנחיות והטקסטים המוצגים ב-Moodle ימשיכו להיות בעברית מלאה.
- אוטומציית המשימות מנוהלת דרך סקריפטים (כדוגמת `generate_all_grader_tasks.js`). שינוי במשימה או בפתרון מחייב הרצה של הסקריפט לעדכון כלל הקבצים.

## 7. כתיבת קוד
- יש לשמור על קוד נקי, מודולרי ומתועד היטב.
- עקוב אחר סגנון הכתיבה הקיים בסקריפטים. אל תבצע Refactor נרחב לקוד עובד מבלי לתאם זאת, וודא שאין שבירת תאימות לאחור (Backward Compatibility) במיוחד בעבודה מול מבנה התיקיות הקיים של ה-Moodle Book.

## 8. מבנה בחני H5P סופיים
- **תלויות (Dependencies):** יש לוודא שימוש במודולים הנדרשים כגון `H5P.QuestionSet`, `H5P.MultiChoice`, ובפרט `H5P.MathDisplay` להצגת משוואות ומתמטיקה.
- **שפה וממשק (UI & Texts):** כל מחרוזות הממשק (כפתורים כמו "בדוק", "הצג פתרון", "הגש") חייבות להיות מתורגמות לעברית בהתאם לתבניות הקיימות בסקריפטים (אובייקטי `ui` ו-`texts`).
- **כיווניות ועברית תקינה (RTL & Hebrew):** יש להקפיד על ניסוח בעברית תקינה ורהוטה. בנוסף, חובה לוודא תמיכה מלאה בכיווניות מימין לשמאל (RTL) בתוכן השאלות, בתשובות ובמשובים. במידת הצורך, יש לעטוף טקסטים או לשלב הגדרות מתאימות כדי למנוע היפוך של סימני פיסוק ובעיות תצוגה כשמשלבים עברית עם מתמטיקה או אנגלית.
- **נוסחאות ומתמטיקה:** כתיבת נוסחאות במבחני H5P מתבצעת באמצעות תחביר MathJax בתוך עטיפה של לוכסנים וסוגריים, לדוגמה: `\( V_{RMS} = V_p / \sqrt{2} \)`.
- **מבנה שאלות ומשוב:** כל שאלה צריכה לכלול משוב מפורט (Feedback) שמסביר מדוע התשובה נכונה או שגויה, כדי לספק ערך לימודי מקסימלי.
- **הגדרות התנהגות (Behaviour):** יש להגדיר אפשרויות חזרה (Retry) והצגת פתרונות (Solutions) לפי הסטנדרט המקובל בקבצי יצירת ה-H5P בפרויקט (למשל `enableRetry: true`, `enableSolutionsButton: true`).
- **תהליך חידוש ותיקון קבצים (Regeneration):** אם מתגלה שגיאה בבחינת H5P (למשל בעיית כיווניות, עברית לא תקינה או טעות בשאלה) - **אין לערוך את קבצי ה-H5P הסופיים ידנית**. יש לתקן את תוכן השאלות בתוך סקריפטי המחולל המתאימים בתיקיית `scripts/assessments_and_h5p/` (כגון `generate_exp02_prelab_h5p.js`). לאחר ביצוע התיקון בסקריפט, יש להריץ אותו דרך ה-Terminal (לדוגמה: `node scripts/assessments_and_h5p/generate_exp02_prelab_h5p.js`). הרצת הסקריפט תייצר מחדש את קבצי ה-`.h5p` התקינים תחת תיקיית המקור (`src/content/...`).
